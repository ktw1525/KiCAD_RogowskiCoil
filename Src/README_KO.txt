==============================================================

개발자: ktw1525
저장소: https://github.com/ktw1525/KiCAD_RogowskiCoil

패키지 식별자: org-ktw1525-rogowski-coil-generator

설치
----
1) 기존 Rogowski Coil Generator v0.4.0 제거 (PCM -> 설치됨 -> 제거 -> 적용).
2) KiCad 종료 후 실행.
3) PCM -> 파일에서 설치 -> Rogowski_TI_Gerber_PCM_KiCad10.zip (압축해제하지 않음).
4) 변경 사항 적용 -> PCB 편집기 다시 열기.
5) 도구 -> 외부 플러그인 -> Rogowski TI Gerber Coil Generator.
6) 구리 레이어가 2개 이상인 PCB에서 실행. 활성 레이어 중 서로 다른 2개를 선택.
7) 치수를 입력하고 '치수 검증'을 실행. 검증 통과 후에만 생성 버튼이 활성화됨.
8) 숫자나 홀/외곽선 옵션을 수정하면 검증이 무효화되므로 다시 검증해야 함.
9) 검증 실패 시 입력창에서 오류를 확인하고 치수를 수정. 검증은 PCB를 변경하지 않음.

원본 근거
---------
사용자 제공 TI TIDA010971E2.0 Gerber / NC drill:
 .GTL: F.Cu, .GBL: B.Cu, .TXT: plated drill
 코일 중심 좌표: (123.0165, 95.7451) mm (드릴 기준)
 코일 4개 동심원(중심 반경): 2.2350 / 2.90185 / 4.8800 / 5.2650mm
 각 원에 16개 관통 비아 -> 64개 코일 관통 비아
 좌측 인출부 추가 2개 비아 -> 총 66개
 비아 패드 지름 0.45mm / 드릴 0.20mm (T1)
 F.Cu/B.Cu 권선 트랙 0.10mm (Gerber aperture D132)
 중앙 홀 드릴 지름 3.0mm (T11, 원본 PTH) - 플러그인 옵션은 Edge.Cuts 개구부(비도금)로 생성하므로 원본과 가공 공법이 다름.

전기적 연결
------------
64개 원형 비아 + 좌측 인출부의 2개 비아를 각 레이어 도체와 함께 구성해 연결성을 분석함.
원본의 두 경로는 각각 끊김 없는 권선이며, v0.6.1에서는 바텀 패드 3·4에서 연결함.
생성 창에서 단자 1·2에 연결할 기존 PCB 네트를 선택하거나 새 네트 이름을 입력함.
1/3번 및 권선 A는 패드 1 네트, 2/4번 및 권선 B는 패드 2 네트를 사용함.
기본 이름 ROGOWSKI_A/B는 변경 가능하며 TI 원본 넷 이름을 의미하지 않음.
두 번째 선택 레이어에서 3·4를 구리 배선으로 단락시킴. 별도 네트 이름 입력 없음.
외층의 3·4 연결은 네트타이 풋프린트, 내층은 네트 없는 구리 연결 도형으로 생성함.
내층의 의도한 3·4 접점은 KiCad DRC에서 단락으로 보고될 수 있으며 자동 제외하지 않음.

모드
----
  '반원·사분원 공통 반경' 기본값은 0.385mm.
  공통 반경 모드의 안쪽 인출선은 반원 위쪽 수평·수직 구간과 아래쪽 연결 경로를
  Top/Bottom이 동일한 중심선으로 공유함. 반원·사분원은 공통 반경을 유지하며,
  전체 회전 시 연결 경로도 함께 회전함. 각 레이어의 권선과 넷은 별도로 유지됨.
  비아 주변 반원(180도)과 사분원(90도)은 모두 입력한 동일 반경으로 생성함.
  끝점을 고정해 다른 반경을 만드는 대신 직선/연결 원호의 접속점을 함께 조정함.
  비아/트랙/이격 및 각도/홀 공간상 적용할 수 없는 반경은 검증 오류로 표시함.
  0은 예전 원호 변형 방식을 사용하는 호환 옵션이며 공통 반경을 보장하지 않음.

  입력칸은 한 줄 높이이며, 커서가 위치한 파라미터에 해당하는 형상을 미리보기에서 노란색으로 강조합니다.
  반경은 해당 비아 열을, 홀은 중앙 개구부를 표시하고, 트랙/비아/드릴/이격/굴곡은 확대 개념도를 제공합니다.

  입력창 오른편에 코일 미리보기가 표시되며 입력 변경 후 자동 갱신됩니다.
  마우스 휠로 포인터 위치를 기준으로 확대·축소하고 왼쪽 버튼 드래그로 이동합니다.
  '전체 보기' 버튼 또는 더블 클릭으로 초기 자동 맞춤으로 돌아갑니다.
  입력값을 수정해도 사용자가 조정한 확대 배율과 이동량을 유지합니다.
  '인출 방향 선택' 버튼을 누른 뒤 미리보기에서 인출선이 나갈 방향을 클릭합니다.
  노란 가이드가 마우스를 따라 표시되며, 클릭하면 코일·인출부를 함께 회전합니다.
  왼쪽 0도 / 위쪽 90도 / 오른쪽 180도 / 아래쪽 270도이며 중간 방향도 선택 가능합니다.
  '전체 패턴 회전' 값에도 반영되며, 선택 후 치수 검증을 다시 실행해야 합니다.
  선택한 레이어 색상과 노란색 비아를 표시합니다. 중앙 홀과 외곽선 옵션도 반영됩니다.
  미리보기는 자동 확대된 DRC 검사 전 형상이며, 실제 생성 시 간섭 검사를 수행합니다.
  공통 반경 모드에서는 우측 상단의 분할 원호 사이 직선 우회를 연속 원호로 복원하여
  형상 찌그러짐을 방지합니다. 미리보기와 PCB 생성에 동일하게 적용합니다.
  모든 곡선은 KiCad PCB_ARC 객체로 생성합니다. 반원·사분원도 각각 하나의 호입니다.
  내부 간섭 검사에만 원호 표본점을 사용하며, PCB에는 직선 조각으로 추가하지 않습니다.
  치수 변형으로 비원형이 되는 원본 곡선은 변형된 시작·중간·끝점을 지나는 원호로 복원합니다.
  배선 레이어 1/2를 선택합니다. 기본값은 F.Cu/B.Cu입니다.
  외층 단자는 SMD 패드, 내층 단자는 패드·마스크 없는 채워진 구리 사각형입니다.
  관통/블라인드/매립 비아를 선택한 레이어 범위에 맞게 생성합니다.
  기본 패드 크기는 0.7 x 0.7mm이며 외측 2열 반경에 비례해 조정합니다.
  위쪽 F/B 패드는 1/3번(A), 아래쪽 F/B 패드는 2/4번(B)입니다.
  각 패드는 해당 면의 구리와 솔더마스크 개구부만 가지며 드릴은 없습니다.
  앞면 패드 1·2와 바텀 네트타이 3·4는 별도 풋프린트로 생성합니다.
  네트를 변경하면 치수 검증을 다시 실행해야 합니다.
  하단 인출선 끝은 패드 크기와 간격에 맞게 아래로 연장될 수 있습니다.
  생성한 코일은 그룹으로 묶으며 완료 안내를 닫으면 PCB 편집기가 코일 위치로 이동합니다.

  생성 버튼을 누르면 진행률(%), 경과 시간, 현재 작업 단계가 표시됩니다.
  치수 검사 → 좌표 계산 → 권선 간섭 검사 → PCB 트랙/비아 추가 → 화면 갱신 순서로 진행합니다.
  진행률은 단계별 작업량 기준이며, 남은 시간을 보장하는 수치는 아닙니다.
  완료 또는 오류 발생 시 진행률 창이 닫힙니다.

  권선 위치 32 (기본): 원본 Gerber D132 중심선 직선/원호와 드릴 66개를 복원.
   표본화된 원본 곡선은 실제 원호 객체로 복원. 그 외 구리 영역/타 소자 등은 복제 안 함.
   중심 위치, 전체 회전, 4개 동심원 반경, 트랙 폭, 비아 크기 수정 가능.
   원본처럼 좌측 인출 트랙 포함. 다만 별도 연결 PAD 등 주변 회로 부품은 생성 안 함.
  권선 위치 N=12~96, 32 이외의 4의 배수: 기본 Top/Bottom 단위 배선 템플릿을 반복·변형.
   이 모드는 거버와 1:1 동일 패턴이 아닌 파생 설계다.
   원본 인출부용 각도 영역을 유지하고, 인출부 두 비아·V자 교차·Top/Bottom 선분 형상을 유지함.
   위쪽 인출부 기준점은 유지하고 아래 비아와 왼쪽 아래 꼭짓점은 권선 접속 높이를 따라 이동함.
   아래 비아에서 수직으로 올라간 뒤 권선 쪽으로 수평 연결하며 전체 회전도 함께 적용함.
   코일 접속부에서 위치 수 변화를 처리하고 다른 네트의 구리 겹침을 검사함.
   총 비아 수는 2N+2개. 외부 끝점에 앞면/뒷면 사각 패드 4개를 생성함.
  입력값 '권선 위치 수'는 외측과 내측의 각도를 공유하는 방사형 위치 개수임.
   물리적 코일 턴 수 및 정확한 인덕턴스는 별도 해석·측정 필요.

외곽선
------
 '독립 시험 PCB의 원형 외곽과 중앙 홀 생성'을 체크한 경우에만 Edge.Cuts 추가.
 기존 Edge.Cuts가 있는 PCB에는 이 옵션을 적용하지 않음.
 원본의 중앙 3mm 홀은 plated hole(T11)이지만 여기서는 절연된 보드 개구부(Edge.Cuts)로 대체한다.
 실제 전원 도체의 절연, 간격, 고전압 및 제조 공정 요구사항을 별도 검토.

v0.5.0 GUI 홀 및 외곽 옵션
----------------------
 '중앙 관통홀 생성 (해제하면 홀 없이 생성)'은 레이어 선택 바로 아래에 표시됨.
 기본은 체크 상태이며 Edge.Cuts에 3mm 원형 내부 개구부를 추가함.
 체크를 해제하면 중앙 홀을 추가하지 않고 코일만 생성함. 미리보기에도 홀을 표시하지 않음.
 원형 외곽선 옵션과 독립적으로 사용 가능하며, 기존 PCB의 홀을 삭제하는 기능은 아님.
 기존 PCB에 동일 구멍이 있으면 체크를 해제해야 함.
 독립 원형 PCB 외곽선 생성은 별도 체크, 기본 해제.
 중앙 비도금 홀(Edge.Cuts)은 TI 레퍼런스 PTH 드릴과 가공 종류가 다르며 기구/절연 사양을 직접 결정해야 함.
